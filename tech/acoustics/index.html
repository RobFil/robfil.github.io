Current Harmonics

A technically defined PMSM current-harmonics model with a synchronous rotor reference frame.

Model convention

θ1 = ωet is the rotor-synchronous electrical angle. The fundamental-current reference is a sine: at φ1 = 0, the fundamental component of phase U crosses 0 A in the rising direction at θ1 = 0. With fundamental start angle φ1, signed sequence orders k5 = −5 and k7 = +7 use the same shifted reference: ip,1 = I1 sin(θ1 + φ1 + δp), ip,h = Ih sin(kh(θ1 + φ1) + γh + δp).

δU = 0°, δV = −120°, δW = +120°. Because the harmonics have different frequencies, they have no constant angular separation from the fundamental. The slider γh sets the relative Fourier phase: for the sine form sin(khθ1 + φh), γh = φh − khφ1. The αβ-vector angle at θ1 = 0 is khφ1 + γh − 90° (the sine-to-cosine reference offset). In rotor-synchronous dq, the fundamental is constant at angle φ1 − 90°; harmonic dq orders are k5 − 1 = −6 and k7 − 1 = +6.

The rotor-angle cursor selects an instant; the start-angle control shifts the current waveforms relative to the rotor. The model assumes balanced currents, synchronous rotor speed, and peak values; it excludes inverter voltage limits, saturation, torque, and mechanics.
