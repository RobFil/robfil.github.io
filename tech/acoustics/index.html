Current Harmonics

A technically defined PMSM current-harmonics model with a synchronous rotor reference frame.

Model convention

θ1 = ωet is the rotor-synchronous electrical angle. With fundamental start angle φ1, the signed sequence orders k5 = −5 and k7 = +7 are applied to the same shifted electrical reference: ip,1 = I1 cos(θ1 + φ1 + δp), ip,h = Ih cos(kh(θ1 + φ1) + γh + δp).

δU = 0°, δV = −120°, δW = +120°. The harmonic phase controls γh are additional offsets; the actual αβ angle at θ1 = 0 is khφ1 + γh. In rotor-synchronous dq, the fundamental is constant at angle φ1; harmonic dq orders are k5 − 1 = −6 and k7 − 1 = +6.

The rotor-angle cursor selects an instant; the start-angle control shifts the current waveforms relative to the rotor. The model assumes balanced currents, synchronous rotor speed, and peak values; it excludes inverter voltage limits, saturation, torque, and mechanics.
