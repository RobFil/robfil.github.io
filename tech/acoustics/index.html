TECH // INTERACTIVE LEARNING MODEL

Current Harmonics

A technically defined PMSM current-harmonics model with a synchronous rotor reference frame.

Model convention

θ1 = ωet. Use signed sequence orders k5 = −5 and k7 = +7: ip,h = Ih cos(khθ1 + γh + δp).

δU = 0°, δV = −120°, δW = +120°; γh is the αβ-vector angle at θ1 = 0. Thus iαβ,h = Ihej(khθ1 + γh). In rotor-synchronous dq, idq,h = iαβ,he−jθ1, so the dq orders become k5 − 1 = −6 and k7 − 1 = +6.

Fundamental

−5th harmonic

αβ-vector angle at t = 0: 0° (0°)

+7th harmonic

αβ-vector angle at t = 0: 0° (0°)

Current instant

Phases shown in the harmonic component plot Each selected phase shows both the −5th and +7th components.

The vertical cursor marks the current rotor position without shifting the waveforms. Signed sequence orders set the rotation direction: −5ω and +7ω in αβ. Transforming into the synchronous rotor frame subtracts +ω, giving −6ω and +6ω. The model assumes balanced currents, synchronous rotor speed, and peak values; it does not model inverter voltage limits, saturation, torque, or mechanics.
